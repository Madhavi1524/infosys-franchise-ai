# Milestone 1 – User Authentication Module

## Overview
This project implements a user authentication system as part of Infosys Springboard Internship 7.0, Batch 4, Milestone 1.

## Features
- User Signup with input validation
- User Login with JWT-based session management
- Forgot Password using a security question or email OTP
- User Dashboard with Logout functionality
- Admin Dashboard to view registered users
- Email and password validation

## Technology Stack
- Python
- Streamlit
- JSON Web Tokens (JWT)
- Gmail SMTP for OTP emails
- Google Colab
- ngrok

## How to Run
1. Open the authentication notebook in Google Colab.
2. Configure the required secrets in Colab Secrets.
3. Run the notebook cells in order.
4. Open the Streamlit application using the generated ngrok URL.
